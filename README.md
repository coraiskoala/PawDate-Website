# PawDate Website

Official website for PawDate, a private Chrome extension for tracking pet medication, vaccines, preventive care, appointments, grooming and refill dates.

## Deployment

This is a static website. Import this repository into Vercel and deploy it with the default settings; no framework, build command, environment variables or backend are required.
